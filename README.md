## ⚡ Installation

Clone repository:

```bash
git clone https://github.com/yourusername/AdVantage-Gen.git
cd AdVantage-Gen
```

### Install Frontend

```bash
cd frontend
npm install
npm run dev
```

### Install Backend

```bash
cd backend
npm install
npm start
```

---

## 🔐 Environment Variables

Create `.env` file inside backend:

```env
PORT=5000
MONGO_URI=your_database_url
JWT_SECRET=your_secret_key
```

> Never upload `.env` files to GitHub.
